# WORD QUEST · 초등 필수 800단어 (v0.6)

사용자가 제공한 **「초등 필수 영어단어 800」 PDF**를 기반으로 한 브라우저용 영어 학습 게임입니다. 기존 WORD QUEST의 몬스터 수집, 용사 육성, 퀴즈, 음성 발음, 개인 단어장 기능을 유지하고 **33일 학습 코스와 Anki형 간격 반복 복습**을 더했습니다.

## 실행

1. ZIP 압축을 **모두 해제**합니다. 파일들을 동일 폴더에 둡니다.
2. 터미널에서 해당 폴더로 이동하고 `python -m http.server 8000`을 실행합니다.
3. 브라우저에서 `http://localhost:8000`을 엽니다. 배포할 때는 모든 파일을 같은 웹 디렉터리에 업로드합니다. HTTPS 환경에서는 PWA 설치와 오프라인 캐시가 동작합니다.

`index.html` 파일을 직접 열어도 대다수 기능을 사용 가능하지만, PWA 기능 점검에는 위와 같은 로컬 웹 서버를 권장합니다.

## 파일 구조

- `index.html` — 화면과 반응형 디자인
- `app.js` — 학습, 복습, 퀴즈, 몬스터·용사, 데이터 저장, 비활성화된 OCR 기능 코드
- `words800.js` — PDF에서 추출한 표제어 및 한국어 뜻 800개
- `manifest.webmanifest` — PWA 앱 정보
- `sw.js` — 주요 파일 오프라인 캐시
- `icon.svg` — 앱 아이콘
- `ARCHITECTURE.md` — 기술 구조, 향후 OCR 복원 안내

## 학습 방법

- **홈 → 800단어**: DAY 1~33 중 선택, DAY당 20개(마지막 DAY 33은 17개) 학습.
- **워밍업(36개)**, **기초 기능어(107개)**는 별도 학습 가능합니다.
- 카드 뒤집기 후 **다시 / 어려움 / 알겠어 / 쉬워!** 네 가지로 기억 수준을 평가합니다.
- 복습 예약 시간이 되면 **복습** 메뉴에서 다시 공부합니다. '다시'를 누르면 현재 학습 회차의 끝에도 한 번 더 등장합니다.
- 퀴즈 정답과 카드 평가로 XP를 얻고, 학습 성과로 몬스터를 수집하고 성장시킵니다.

## 저장 및 주의사항

- 데이터는 **현재 브라우저의 localStorage** (`wordquest_v1`)에 저장됩니다. 다른 기기와 자동 동기화되지 않으므로 단어장 메뉴에서 JSON **백업**을 권장합니다.
- 기존 WORD QUEST의 데이터도 같은 브라우저에서 유지하도록 설계했습니다. 기존 데이터가 중요하면 **새 버전을 열기 전에 기존 버전에서 백업**해 두세요.
- 800단어는 최초 실행 시 현재 단어장에 추가됩니다. 전체 단어 삭제 후 재방문하면 기본 800단어가 재등록됩니다.
- OCR은 메뉴에서 숨겼지만 `app.js` 코드에 남아 있습니다. 이 버전에서는 OCR 기능을 사용하지 않습니다.
- 단어의 뜻은 PDF를 그대로 옮겼으므로 일부 표제어에는 다의어·품사 구분이 충분하지 않을 수 있습니다. 외부 사전으로 자동 대체하지 않았습니다.
- 복습 알고리즘은 **단순화된 간격 반복 방식**이며, 공식 Anki FSRS 구현이 아닙니다.

## 출처 및 사용

800단어 목록은 사용자가 제공한 올라영(OLLAYOUNG) 자료의 순서와 표기를 바탕으로 구성했습니다. 원본 교육 자료의 저작권과 재배포 조건을 확인하고 외부 공개 여부를 결정하세요.
