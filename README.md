# ⚡ WORD QUEST

**사진 한 장으로 시작하는 영어 단어 모험**

WORD QUEST는 사진 속 영어 단어를 나만의 단어장과 학습 퀘스트로 연결하는 것을 지향하는 한국어 기반 웹 앱입니다. 어두운 네이비 계열의 게임형 인터페이스와 반응형 레이아웃을 사용합니다.

> 이 README는 제공된 `index.html`(화면 구조 및 스타일)만을 기준으로 작성했습니다. 앱의 실제 동작 로직인 `app.js`가 제공되지 않았으므로 기능 구현 여부와 데이터 저장·인식 방식은 확인되지 않았습니다.

## 주요 화면 및 UI 요소

`index.html`에 정의된 화면 구성과 CSS를 기준으로 다음 요소를 확인할 수 있습니다.

- **대시보드**: 페이지 제목, 레벨 배지, 통계 카드, 메인 배너
- **사진 입력 UI**: 파일 선택·드래그 앤 드롭을 위한 스타일과 스캔 관련 버튼 영역
- **단어 관리 UI**: 단어 입력 행, 단어 목록, 품사 입력 필드 스타일
- **학습 UI**: 플래시카드, 객관식 선택지, 진행률 표시 바, 결과 영역
- **게임 UI**: 몬스터 카드, 몬스터 도감 슬롯, 획득 상태 관련 스타일
- **반응형 탐색**: 데스크톱 측면 메뉴와 모바일 하단 메뉴

위 항목은 화면에 사용할 수 있도록 정의된 **UI 구조/스타일**이며, 실제 기능의 작동 여부는 `app.js`를 확인해야 합니다.

## 기술 구성

- HTML5
- CSS3 (별도 CSS 파일 없이 `index.html` 내부에 포함)
- JavaScript (`app.js` 외부 파일을 불러오는 방식)
- Web App Manifest (`manifest.webmanifest` 참조)
- 한국어 UI (`lang="ko"`)

별도의 프레임워크나 빌드 도구는 제공된 HTML에서 확인되지 않습니다.

## 프로젝트 파일 구조

```text
word-quest/
├── index.html              # 페이지 마크업과 스타일 (제공됨)
├── app.js                  # 앱 동작 로직 (HTML에서 참조, 미제공)
├── manifest.webmanifest    # 웹 앱 매니페스트 (HTML에서 참조, 미제공)
└── README.md               # 프로젝트 설명
```

**중요:** 현재 제공된 파일은 `index.html` 하나입니다. `app.js` 및 `manifest.webmanifest`는 HTML에서 참조하지만 함께 제공되지 않았습니다.

## 실행 방법

1. `index.html`, `app.js`, `manifest.webmanifest`를 같은 폴더에 준비합니다.
2. 해당 폴더에서 로컬 웹 서버를 실행합니다. 예를 들어 Python이 설치되어 있다면:

   ```bash
   python -m http.server 8000
   ```

3. 브라우저에서 [http://localhost:8000](http://localhost:8000)에 접속합니다.

`index.html`만 있는 경우 페이지의 기본 틀과 스타일은 로드될 수 있지만, 화면 내용과 메뉴를 채우는 자바스크립트 기능은 작동하지 않을 수 있습니다.

## 화면 디자인

- **기본 색상**: 네이비 배경, 블루 강조색
- **레이아웃**: 최대 너비 1,200px의 데스크톱 2열 구성
- **모바일 최적화**: 너비 740px 이하에서 하단 내비게이션으로 전환
- **접근성 고려**: 키보드 포커스 스타일과 알림 영역의 `role="status"` 설정
- **기타**: 모바일 화면 안전 영역(`safe-area-inset-bottom`) 고려

## 추가 확인이 필요한 사항

다음 항목은 실제 구현 파일인 `app.js` 등의 확인이 필요합니다.

- 사진에서 영어 단어를 인식하는 기술 및 정확도
- 단어장 등록·편집·삭제와 저장 방식
- 퀴즈 채점, 레벨 및 몬스터 획득 규칙
- 서버·외부 API·인증 사용 여부
- 오프라인 기능 및 홈 화면 설치 지원 여부
