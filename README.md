# WORD QUEST v0.5 — Monsters

이 폴더 전체를 그대로 웹서버에 올리세요. PC에서 이 폴더 내 `python -m http.server 8000` 후 `http://localhost:8000` 접속. 스마트폰은 HTTPS 웹 호스팅에 폴더 전체를 게시한 후 접속하세요.

- 몬스터 12종의 서로 다른 SVG 형태(늑대/드래곤/거북/물정령/골렘/여우/유령/펭귄/황소/가오리/부엉이/사슴)와 3단계 진화
- 기존 단어장·OCR·학습·퀴즈 유지. OCR 정확도는 이번 작업에서 수정하지 않았습니다.
- 기존 데이터 localStorage 키 wordquest_v1 유지. **동일 도메인에서 두 버전을 번갈아 배포할 경우 동일 데이터를 공유**합니다. 시험 전 데이터 백업 권장.
- 초기 UI 시제품이며 스마트폰 실기기 및 전체 동작 테스트는 별도 필요합니다.
- 모든 그래픽은 HTML 내부 SVG, 외부 유료 이미지/API 없음.
