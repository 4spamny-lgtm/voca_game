# WORD QUEST v0.4.1 — OCR 보완

기존 단어장, 몬스터 및 퀴즈 기능은 유지합니다. 사진을 확대·대비 보정한 뒤 무료 OCR을 실행하고, 한글 뜻을 못 읽어도 식별된 영어 표제어를 **⚠ 뜻 확인 필요**로 저장할 수 있도록 개선했습니다. 단어장 편집에서 뜻을 수정하세요.

주의: 극히 작은 한글은 원본에 픽셀이 부족하면 무료 OCR로 복원 불가능합니다. 이 경우 원본 사진을 더 가까이 촬영하여 주세요. 이번 패치는 실제 스마트폰에서 검증되지 않은 실험 버전입니다.

실행: `python -m http.server 8000` 후 `http://localhost:8000`을 열어 사용합니다. 스마트폰에서는 HTTPS 호스팅 필요.

## v0.4.2 추가 기능
- 단어장 화면에서 **전체 단어장 삭제**: 확인창에 `전체삭제` 입력 시 모든 단어와 복습 상태를 삭제합니다.
- 몬스터/XP/레벨은 유지됩니다. 삭제한 단어는 복구할 수 없으므로 필요하면 먼저 **백업**하세요.
