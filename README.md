# WORD QUEST v0.9 — 모험 지도

## 변경 내용
- **모험 지도 = 홈**: DAY 1~33을 구불구불한 지역별 경로로 표시합니다.
- 5개 메뉴: **모험 / 배틀 / 용사 / 도감 / 더보기**.
- DAY 완료 시 다음 스테이지가 열리며, 완료한 DAY는 다시 도전할 수 있습니다. 미완료 스테이지는 잠깁니다.
- 상단에 용사·파트너, 레벨·XP, DAY 진척률, **오늘 시작!**, **기억 도전** 버튼을 표시합니다.
- 기존 보상, 몬스터, RPG 배틀, 간격 반복 기록을 유지합니다.
- DAY 별 1~3개는 재도전에서 얻은 가장 높은 기억 평가 비율로 기록합니다(70% 미만 1개, 70% 이상 2개, 95% 이상 3개). 이는 기억 자신감 표시이며 객관식 정답률과 다릅니다.
- 숫자·색깔 / 기능어 / 백업 / 전체 초기화는 더보기에서 이용합니다.

## 실행
압축 해제 후 `index.html`을 실행합니다. PWA 설치 및 오프라인 캐시는 HTTPS 또는 로컬 웹 서버가 필요합니다. 기존 localStorage `wordquest_v1`을 이어 사용합니다. 먼저 백업을 권장합니다.

## 참고
새 DAY 해금은 앞 DAY의 모든 단어를 최소 한 번 평가했을 때 발생합니다. 기존 기록이 있으면 완료 상태를 자동으로 계산합니다. 특별 보상은 기존과 동일하게 중복 지급하지 않습니다.


## v1.0 지도 개선
- 구불구불 이어지는 DAY별 모험길과 경로 색상 표시
- 지도 상단 '내 위치 찾기' 버튼 및 4개 지역 바로 이동
- 현재 DAY 진행량 표시, 완료한 DAY 재도전, 잠긴 DAY 제한
- 기존 학습 데이터 및 RPG 시스템 유지


## v1.1 화면 개선
- 숲·협곡·설산·성마다 나무, 선인장, 바위, 설산, 성채 장식과 전용 색상 적용
- 스테이지 주변 배경을 지역 분위기에 맞게 변경
- 홈의 기억 도전 버튼을 오늘 시작과 같은 크기로 확대하고 보라색으로 강조
- DAY 진척도, 복습 일정, 전투 및 보상 기록은 기존 브라우저 저장소 유지
