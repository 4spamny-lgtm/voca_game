# WORD QUEST v0.8 — 800단어 RPG 모험

`index.html`을 열어 시작하세요. 설치형 PWA나 서비스워커는 로컬 서버/HTTPS에서 동작합니다.

## 업데이트
- 홈의 **오늘 시작!** 버튼으로 즉시 해당 DAY 카드 시작
- 어린이용 메뉴 6개: 홈 / 모험 지도 / 기억 던전 / 배틀 / 내 캐릭터 / 설정
- 도감 및 단어장은 내 캐릭터 화면에서 열기
- 카드 안내문 최소화, 쉬운 네 단계 평가(다시·아차·기억나·완전 쉬워)
- DAY 완료 시 보상: 일반 DAY +15XP, DAY 1/5/10/20/33 특별 보상 (한 번만 지급)
- 배틀: 정답 공격/오답 피해, 장비 공격력 적용, 파트너 보유 시 3연속 정답 특별 공격, 보스 처치 +40XP
- 전체 초기화 및 백업/복원 유지

## 주의
기존 로컬 저장소 `wordquest_v1`을 이어 사용합니다. 업데이트 전 설정에서 백업하세요. OCR 코드는 보존했지만 메뉴에는 숨겨 두었습니다. 현재 전투는 정적인 SVG 기반의 가벼운 턴제 퀴즈 RPG입니다.
